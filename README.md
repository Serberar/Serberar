### El buen software se nota cuando hay que cambiarlo.

Diseño y construyo producto de principio a fin: el modelo de dominio, la API, la interfaz, las pruebas y el despliegue. Prefiero el código que otra persona puede entender, probar y cambiar sin miedo.

> **Ahora:** creo y desarrollo **[RecruitSpace](https://recruitspace.es/)**, un SaaS multi-tenant de selección de personal en producción. Es un proyecto personal de software libre. Backend en Node.js, TypeScript y Prisma con arquitectura hexagonal, frontend en React e infraestructura en Docker. Más de 20 años construyendo para la web.

### Principios

1. **Entender antes de escribir.** El cambio más pequeño que resuelve el problema completo.
2. **Probar el comportamiento.** Una prueba vale por el fallo que evita, no por la cobertura que suma.
3. **Fallar con claridad.** El error se registra entero y al usuario se le dice qué puede hacer.
4. **Automatizar lo repetido.** Pruebas, compilación y publicación en cada cambio.
5. **Documentar lo justo.** Un README que permite arrancar y explica el porqué.
